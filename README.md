Ce projet est une application web légère développée avec Flask pour traiter et gérer des fichiers log via une interface web.

## Contenu du projet

* **app.py** : Script principal de l'application Flask.
* **static/** : Contient les fichiers statiques (CSS).
* **templates/** : Contient les templates HTML de l'application.

## Prérequis

Avant de lancer l'application, assurez-vous d'avoir Python installé (version 3.7 ou supérieure recommandée) et pip.

### Installation des dépendances

```bash
pip install Flask
```
